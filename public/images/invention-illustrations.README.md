# Featured invention illustrations

Three concept illustrations generated with the built-in image generator. The existing Unisba innovation banner was the style reference: dark ink, soft pastel blocks, navy/ivory/teal/champagne palette, hijabi researchers and an engineer in peci.

- `patent-wound-cream-v1.webp`: formulation research for application P00201601452.
- `patent-water-apple-v1.webp`: water-apple leaf extract and oral suspension research for S00202406986.
- `patent-waste-energy-v1.webp`: closed-system recycling residue energy concept for P00201508092.

These are theme illustrations, not actual product photographs, engineering drawings or evidence of efficacy. Source patent descriptions were unavailable; only the recorded titles guide the subjects. Exact application mapping lives in `src/featured-illustrations.js`. All files are optimized square 768px WebP and loaded lazily.
